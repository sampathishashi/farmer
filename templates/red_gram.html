🌱 Soil Agent Notification System

Real-time notifications for soil analysis requests from farmers

🚀 How It Works

The soil agent notification system automatically notifies agents when farmers request soil analysis. Here's how it works:

1. Farmer Request

Farmer fills out soil analysis request form with their details and intended crop

View Farmer Form

2. Agent Notification

Agent receives immediate notification with farmer details and contact information

View Agent Dashboard

3. Response & Processing

Agent can accept, contact farmer, schedule visit, or start processing the request

Fill Soil Report

🔔 Notification Features

  • Real-time Updates: Notifications appear immediately when farmers submit requests
  • Priority System: High priority alerts for urgent soil analysis requests
  • Action Buttons: Quick response options (Accept, Contact, Schedule, Mark as Read)
  • Auto-refresh: Dashboard updates every 30 seconds for new notifications
  • Detailed Cards: Each notification shows complete farmer information

📅 Visit Scheduling System

The system now includes a comprehensive visit scheduling feature:

  • Date & Time Selection: Agents can pick specific dates and times for soil sampling visits
  • Notes & Instructions: Add specific notes or instructions for the visit
  • Farmer Notification: Farmers receive immediate notifications about scheduled visits
  • Visit Tracking: Track all scheduled visits and their status

📊 Enhanced Soil Report Notifications

When agents complete soil analysis reports, farmers receive detailed notifications including:

  • Complete Soil Analysis Results: Nitrogen, Phosphorus, Potassium, pH, Texture, Organic Matter
  • Crop Recommendations: Specific crops suitable for the soil conditions
  • Fertilizer Guidelines: Detailed fertilizer recommendations
  • Agent Information: Contact details of the soil agent
  • Report Timestamp: When the analysis was completed

🛠️ System Requirements

  • Database: MongoDB with collections for users, agents, soil_requests, notifications, and soil_reports
  • Backend: Flask application with proper session management
  • Frontend: Responsive HTML templates with JavaScript for real-time updates
  • Authentication: Secure login system for farmers and agents

🔧 Setup Instructions

  1. Run python add_agents.py to create soil agent accounts
  2. Start the Flask application: python convert_crops.py
  3. Login as a farmer to request soil analysis
  4. Login as an agent to receive notifications
  5. Test the notification system by creating multiple requests
