📋 How to Test the Notification System

  1. Start the Flask Application: Run python convert_crops.py in your terminal
  2. Login as Soil Agent: Use credentials for a soil agent account (e.g., ramesh.adilabad@agri.com)
  3. View Dashboard: Go to the soil agent dashboard at /soilagent
  4. See Notification: The notification card for "shashi kumar" will appear with all action buttons
  5. Test Actions: Click the buttons to test different responses

🔧 Available Actions

✅ Accept Request Marks the request as accepted and notifies the farmer
📞 Contact Farmer Shows farmer contact details for immediate communication
📅 Schedule Visit Opens a modal to schedule soil sampling visit
✓ Mark as Read Removes the notification from the urgent list

📊 Request Status Flow

🆕 Pending Initial status when farmer submits request
🔄 Processing Agent starts working on the soil analysis
📋 Fill Report Agent completes soil analysis and recommendations
✅ Completed Final status when report is delivered to farmer
